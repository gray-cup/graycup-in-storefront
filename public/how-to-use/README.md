# How to Use GIFs

Drop one GIF per brew method here, matching the filenames referenced in
`src/data/how-to-use.ts`. Convert screen-recorded/MP4 demo videos to GIF
(e.g. with `ffmpeg` or a tool like Gifski) so the "How to Use" page
(`/how-to-use`) loads fast — keep each file under ~3-5 MB.

Expected filenames:

- french-press.webm
- whole-beans.gif
- espresso.gif
- moka-pot.webm
- south-indian-filter.gif
- pour-over.gif
- aeropress.gif

Until a file is added, the page shows a "Demo video coming soon" placeholder
for that grind size instead of a broken image.
